# مدیر پروژه

**مدیر پروژه** یک وب‌اپلیکیشن ساده و فارسی برای مدیریت کارها به سبک کانبان است. این برنامه با رابط راست‌به‌چپ و یک تختهٔ آماده شامل پنج ستون و کارت‌های نمونه باز می‌شود. می‌توانید نام ستون‌ها را تغییر دهید، ستون تازه بسازید و کارت‌ها را در ستون‌ها اضافه، حذف یا جابه‌جا کنید.

## امکانات

- رابط کاربری فارسی و راست‌به‌چپ، سازگار با اندازه‌های مختلف صفحه
- یک تخته با پنج ستون نمونه: «ایده‌ها»، «برنامه‌ریزی»، «در حال انجام»، «بازبینی» و «انجام‌شده»
- تغییر نام ستون‌ها و افزودن ستون با نام دلخواه؛ ستون تازه در سمت چپ تخته قرار می‌گیرد
- پیمایش افقی تخته و حفظ عرض ستون‌ها هنگام افزایش تعداد ستون‌ها
- افزودن کارت با عنوان و جزئیات، حذف کارت، و مرتب‌سازی یا انتقال کارت با کشیدن و رها کردن
- نگهداری تغییرات فقط در حافظهٔ مرورگر؛ با بارگذاری دوبارهٔ صفحه، تخته با داده‌های نمونه بازمی‌گردد

این نسخه عمداً ذخیره‌سازی دائمی، حساب کاربری، تخته‌های متعدد، جست‌وجو، فیلتر و حذف ستون را شامل نمی‌شود.

## فناوری‌ها

- [Next.js](https://nextjs.org/) و [React](https://react.dev/)
- [TypeScript](https://www.typescriptlang.org/)
- [dnd-kit](https://dndkit.com/) برای تعامل‌های کشیدن و رها کردن
- [Vitest](https://vitest.dev/) و [Playwright](https://playwright.dev/) برای آزمون‌ها

## پیش‌نیازها

- Node.js نسخهٔ ۲۰٫۹ یا جدیدتر
- npm
- برای آزمون مرورگر: Microsoft Edge

## اجرا در محیط توسعه

دستورها را از پوشهٔ `frontend` اجرا کنید:

```bash
cd frontend
npm ci
npm run dev
```

سپس نشانی [http://localhost:3000](http://localhost:3000) را در مرورگر باز کنید.

## فرمان‌های پروژه

| فرمان | کاربرد |
| --- | --- |
| `npm run dev` | اجرای سرور توسعه |
| `npm run build` | ساخت نسخهٔ آمادهٔ انتشار |
| `npm run start` | اجرای نسخهٔ ساخته‌شده؛ ابتدا `npm run build` را اجرا کنید |
| `npm run lint` | بررسی کد با ESLint |
| `npx tsc --noEmit` | بررسی نوع‌ها با TypeScript |
| `npm test` | اجرای آزمون‌های واحد با Vitest |
| `npm run test:watch` | اجرای آزمون‌های واحد در حالت مشاهده |
| `npm run test:e2e` | اجرای آزمون‌های مرورگر با Playwright |

آزمون‌های مرورگر از Microsoft Edge نصب‌شده روی دستگاه استفاده می‌کنند.

## ساختار پوشه‌ها

```text
frontend/
├── e2e/                 # آزمون‌های مرورگر
├── public/              # فایل‌های عمومی و لوگوی برنامه
├── src/
│   ├── app/
│   │   ├── globals.css  # سبک‌ها و طرح‌بندی رابط
│   │   ├── layout.tsx   # فراداده و تنظیم زبان و جهت صفحه
│   │   └── page.tsx     # صفحهٔ تعاملی تخته
│   └── lib/
│       ├── board.ts     # مدل و عملیات تخته و کارت‌ها
│       └── board.test.ts
└── package.json
```

## وضعیت داده‌ها

اطلاعات تخته فقط تا زمانی که صفحه باز است در حافظهٔ سمت کاربر نگهداری می‌شود. داده‌ها به سرور ارسال نمی‌شوند و در پایگاه داده یا مرورگر ذخیرهٔ دائمی ندارند؛ بنابراین با بارگذاری دوبارهٔ صفحه، نمونه‌های اولیه نمایش داده می‌شوند.
